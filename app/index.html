Nur dieses Gerät

Profil teilen

Kopiere den Code und schick ihn an einen Kollegen (Discord, WhatsApp). Er öffnet Setup Vault, tippt auf „Code einfügen“ und hat dein Profil.

Code einfügen

Füge den Code ein, den du bekommen hast. Das Profil kommt als neues Profil dazu, deine eigenen bleiben unverändert.

Spiel hinzufügen

Zum Beispiel Valorant, Fortnite, Apex Legends oder Rainbow Six Siege.

Handy verbinden

Handy ins gleiche WLAN wie den PC. Dann mit der Handy-Kamera den passenden Code scannen.
